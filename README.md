# 🏥 Cabinet Médical - Application de Gestion

Application web complète pour la gestion d'un cabinet médical (patients, médecins, rendez-vous, consultations).

## ✨ Fonctionnalités

### 👥 Patients
- Ajouter, modifier, supprimer, consulter un patient


### 👨‍⚕️ Médecins
- Gestion des médecins (spécialité, coordonnées)

### 📅 Rendez-vous
- Planification, modification, annulation

### 💊 Consultations
- Enregistrement des diagnostics, traitements, notes
- Poids et tension artérielle

### 📊 Dashboard
- Statistiques (patients, médecins, RDV du jour)
- Graphiques d'activité

### 🔐 Authentification
- Inscription, connexion, déconnexion
- Pages protégées
